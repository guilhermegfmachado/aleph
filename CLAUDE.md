# Aleph — Universal Literary Catalogue

A single-page app indexing public domain literature across all traditions, featuring:
- **Browse**: 50+ texts from Greek, Latin, Sanskrit, Japanese, Chinese, and more
- **Glossary**: 330+ untranslatable concepts across 38 languages
- **References**: 479 curated sources with D3 network visualization

Stack: Vanilla JS, CSS custom properties, hash routing, GitHub Pages
