========================================
         HOW TO USE BORGES
    The Searchable Library of Babel
========================================

Search and browse classical texts from Homer to Seneca.
No AI, no API keys, no monthly fees - everything runs locally.


STEP 1: INSTALL (one time)
-----------------------------------------
Open a terminal/command prompt and run:

    cd /home/user/claude-projects/ancient-books-rag
    pip install -e .


STEP 2: RUN
-----------------------------------------
    python setup_and_run.py

First time: downloads 100 classical texts (takes a few minutes)
After that: starts instantly


STEP 3: USE
-----------------------------------------
1. Open your browser (Chrome, Firefox, etc.)
2. Go to: http://localhost:8000
3. Type a search term: love, death, justice, virtue...
4. Click on results to read full texts


FEATURES:
-----------------------------------------
✓ Search across all texts instantly
✓ Browse by author or source
✓ Upload your own books (PDF, TXT, EPUB)
✓ Works offline after initial download


ADD MORE BOOKS:
-----------------------------------------
From MIT Classics (441 works):
    python scripts/populate_library.py --source mit

From Project Gutenberg:
    python scripts/populate_library.py --source gutenberg

From Sacred Texts Archive:
    python scripts/populate_library.py --source sacred

All sources:
    python scripts/populate_library.py --source all


UPLOAD YOUR OWN:
-----------------------------------------
1. Go to http://localhost:8000/upload
2. Choose a file (PDF, TXT, EPUB, HTML)
3. Click Upload


TO STOP:
-----------------------------------------
Press Ctrl+C in the terminal


COST:
-----------------------------------------
$0. Everything runs on your computer.
